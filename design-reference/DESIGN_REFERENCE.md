# Design Reference

These two images are approved visual references for the Tutor Management System.

## student-dashboard-reference.jpeg
Reference for the student/parent dashboard:
- Clean, bright educational interface
- Hebrew RTL layout
- White/light background with subtle blue-gray sections
- Deep navy blue as the main brand color
- Turquoise/cyan accents
- Soft green, purple and orange secondary accents
- Rounded cards with light shadows
- Clear visual hierarchy
- Friendly but professional educational feel
- Sidebar navigation on desktop
- Responsive/mobile-first adaptation required
- Light Mode reference; Dark Mode must be designed consistently

## tutor-dashboard-reference.jpeg
Reference for the tutor/admin dashboard:
- Same brand language as the student dashboard
- KPI cards for daily/weekly/monthly data
- Lesson requests with clear approve/reject actions
- Pending payments
- Calendar
- Upcoming lessons
- Statistics/analytics
- Hebrew RTL layout
- Professional but friendly, not a heavy corporate CRM
- Light Mode reference; Dark Mode required

## Important
These are visual references, not pixel-perfect specifications.
Preserve the visual language and hierarchy while improving UX where appropriate.
Do not blindly copy elements that conflict with the approved product requirements.
