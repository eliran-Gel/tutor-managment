# צ'ק ליסט - פערים מהביקורת העסקית

מבוסס על הביקורת מ-30-31/08/2026. סרטונים הוצאו מהסקופ במפורש (תלוי בצילום של המורה,
לא בפיתוח). מסודר לפי סדר ביצוע מומלץ - יחס השפעה/מאמץ, לא לפי דחיפות גולמית.

מקרא מאמץ: 🟢 קטן (שעה-שעתיים) · 🟡 בינוני (כמה שעות, טבלה/RPC חדשים) · 🔴 גדול (פיצ'ר שלם)

## בוצע
- [x] תיקון מדיניות ביטול באתר השיווקי - תואם עכשיו את המערכת (0%/50%/100%)
- [x] ייצוא הכנסות לאקסל (CSV) בעמוד האנליטיקה

## הבא בתור

1. [ ] 🟢 **SEO בסיסי** (אתר שיווקי) - meta description, Open Graph, נתונים מובנים. קוד בלבד, אין תלות חיצונית.
2. [ ] 🟡 **טופס לידים** (אתר שיווקי → מערכת ניהול) - טופס קצר (שם/טלפון/מקצוע/כיתה) שנוחת כ"פנייה חדשה" אצל המורה.
3. [ ] 🟢 **מדידה (Google Analytics)** - קוד מהיר; המורה צריך ליצור חשבון GA4 (חינם).
4. [ ] 🟢 **פרופיל עסקי בגוגל** - פעולה חיצונית של המורה בלבד (20 דקות), חינמי. אני רק מדריך.
5. [ ] 🔴 **מעקב ציונים והתקדמות** (מערכת ניהול) - הפער הכי משמעותי. מזין גם את "הוכחת תוצאות" באתר וגם דוח הורים.
6. [ ] 🔴 **מסך הורים אמיתי** (מערכת ניהול) - תפקיד קיים במסד הנתונים, אין מסך בפועל.
7. [ ] 🟡 **שיעורים קבועים/חוזרים** (מערכת ניהול) - חוסך יצירה ידנית שבועית.
8. [ ] 🟡 **חיבור רשימת המתנה לביטולים** - התראה אוטומטית כשמתפנה משבצת.
9. [ ] 🟢 **הצעת כניסה בלי סיכון** (אתר שיווקי) - שיעור ניסיון/אבחון מוזל. דורש החלטת תמחור מהמורה.
10. [ ] 🟢 **המלצות בטקסט** (אתר שיווקי) - לצד גלריית הצילומים. דורש שהמורה יספק שמות/ציטוטים.
11. [ ] 🟢 **הצגת תעודת ההצטיינות** (אתר שיווקי) - דורש תמונה מהמורה.
12. [ ] 🟡 **מדיניות פרטיות + תנאי שימוש + פרטי עוסק** (אתר שיווקי) - טיוטה שלי, דורש פרטי עוסק מהמורה.
13. [ ] 🟢 **קבלות** - הרשמה חיצונית ל-SUMIT (מסלול חינם), פעולה אישית של המורה. לא נבנה בתוך המערכת.
14. [ ] 🟡 **הגשת שיעורי בית** (תלמיד) - העלאת תמונת פתרון, לא רק סימון "בוצע".
15. [ ] 🟡 **יומן מסונכרן לתלמידים** - הרחבה של תשתית ה-ICS הקיימת (כרגע רק למורה).
16. [ ] 🟡 **ערוץ שאלות בתוך המערכת** (תלמיד↔מורה) - במקום הכל בוואטסאפ.
17. [ ] 🟢 **ספירה לאחור לבגרות** (תלמיד י"ב).
18. [ ] 🟡 **חבילות שיעורים מראש** - דורש החלטת תמחור מהמורה.
19. [ ] 🟢 **סימון תלמיד נוטש** (מערכת ניהול) - התראה על תלמיד פעיל בלי שיעור 3+ שבועות.
20. [ ] 🟡 **בנק שאלות/ספריית חומרים** (מערכת ניהול) - האתר כבר מבטיח את זה, המערכת לא תומכת בו.
21. [ ] 🟢 **אפשרות הרכבת קבוצה** (אתר שיווקי) - רשימת עניין לשיעור קבוצתי.
22. [ ] 🟡 **תשלום מקוון** (תלמיד) - כרגע רק קישורי ביט/פייבוקס חיצוניים.
